# 메뉴별 조리 예시 이미지

84개 레시피 각각에 대응하는 WebP 이미지입니다. `b1`~`b32`는 아침, `d1`~`d52`는 저녁이며 파일명은 `recipes.js`의 메뉴 ID와 같습니다.

- 제작 도구: ChatGPT 내장 이미지 생성 도구
- 각 메뉴의 재료와 조리 순서를 바탕으로 개별 제작
- 주재료와 조리 형태를 육안으로 검수
- 1,000px 너비 WebP, 목록에서는 지연 로딩
- 오늘 메뉴·일주일 식단·목록·상세에서 동일한 메뉴 전용 파일 사용
- 전체 제작 프롬프트: [prompts.json](prompts.json)

실제 조리 사진이 아닌 AI 조리 예시입니다. 가족별 실제 재료 수량은 앱의 재료표를 기준으로 합니다.
