# 오늘한끼

13세 아들과 44세 남편을 위한 간단한 아침·저녁 메뉴 웹앱입니다.

[웹앱 열기](https://jsh0529-beep.github.io/saju/oneul-hankki/)

## 기능
- 5~15분 기준 아침 12개, 저녁 12개 레시피
- 음식군별 참고 이미지, 단계별 조리법, 조리 타이머
- 두 사람의 식사량에 맞춘 재료 수량 조절
- 준비 시간 및 제외할 재료 설정
- 일주일 식단과 합산 장보기 목록
- 즐겨찾기, 식단·레시피·장보기 복사

설정과 기록은 사용한 브라우저의 localStorage에 저장됩니다. API 키나 로그인은 필요하지 않습니다.
일반 가족 식사 예시이며 하루 영양 충족을 계산하거나 의료용 식단을 제공하지 않습니다.
이미지는 AI로 제작한 4종의 음식군별 참고 이미지로 실제 재료·분량과 다를 수 있습니다.

## 구성
`index.html`, `style.css`, `recipes.js`, `engine.js`, `app.js`, `manifest.webmanifest`, `assets/`.
서버 없이 정적 파일로 실행됩니다. 모든 실행 자산을 이 폴더에 포함했습니다.
