# 오늘한끼

가족의 관계·나이·식사량을 설정해 간단한 아침·저녁 메뉴를 고르는 웹앱입니다. 처음에는 13세 아들과 44세 남편이 등록되어 있으며 자유롭게 변경할 수 있습니다.

[웹앱 열기](https://jsh0529-beep.github.io/saju/oneul-hankki/)

## 기능
- 간단한 한식 60개를 추가한 총 84개 레시피: 아침 32개, 저녁 52개
- 기본 2인분 기준 5~15분 메뉴, 한식만 보기·매운 메뉴 제외·8개 종류별 검색
- 음식군별 참고 이미지, 단계별 조리법, 조리 타이머
- 가족 1~12명 추가·수정·삭제, 관계·이름 또는 별칭·나이 설정
- 가족별 0.5~2인분 선택, 합계에 맞춰 조리법 재료와 장보기 수량 자동 조절
- 준비 시간 및 제외할 재료 설정
- 일주일 식단과 합산 장보기 목록
- 즐겨찾기, 식단·레시피·장보기 복사

설정과 기록은 사용한 브라우저의 localStorage에 저장됩니다. 기존 아들·남편 설정과 즐겨찾기는 자동으로 이어집니다. API 키나 로그인은 필요하지 않습니다.
일반 가족 식사 예시이며 하루 영양 충족을 계산하거나 의료용 식단을 제공하지 않습니다.
나이는 가족 정보 표시용이며 식사량이나 칼로리를 자동 결정하지 않습니다. 가족이 늘면 조리 시간과 조리도구도 조정해 주세요. 해동·불림 등 사전 준비는 해당 조리법에 안내합니다.
이미지는 AI로 제작한 8종의 음식군별 참고 이미지로 실제 재료·분량과 다를 수 있습니다. SVG 파비콘과 홈 화면용 PNG 아이콘을 포함합니다.

## 구성
`index.html`, `style.css`, `recipes.js`, `engine.js`, `app.js`, `manifest.webmanifest`, `assets/`.
서버 없이 정적 파일로 실행됩니다. 모든 실행 자산을 이 폴더에 포함했습니다.

## 검증
Node.js로 `node checks/recipes.cjs`와 `node checks/family.cjs`를 실행합니다. 메뉴 데이터·조건별 추천·장보기 합산과 기존 설정 이전·가족 추가/수정/삭제 흐름을 검사합니다.
