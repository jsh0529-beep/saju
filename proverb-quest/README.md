# 하준이의 속담 탐험 · Proverb Quest

13세 학습자를 위한 영어·일본어 속담과 표현 학습 앱. 외부 라이브러리나 API 키가 필요 없는 정적 웹앱입니다.

**실행 주소:** https://jsh0529-beep.github.io/saju/proverb-quest/

## 구성

- 영어 24개, 일본어 24개. 일본어 `不言実行`은 사자성어로 명시했습니다.
- 시작의 숲 / 지혜의 도시 / 친구의 섬 / 용기의 우주: 각 세계 12장.
- 뜻·직역·직접 쓴 예문·단어·상황과 언어 간 의미 차이를 담은 카드.
- 뜻 맞히기, 문장 조립, 듣기, 상황 적용 게임. 시간제한 없음.
- 언어 선택, 히라가나, 한글 발음 도움말, 음성 선택과 느리게 듣기.
- 즐겨찾기, 검색, 복습, 경험치·레벨·성취 배지, 학습 기록 JSON 내보내기/가져오기.
- 웹앱 설치, 범위를 이 디렉터리로 제한한 서비스 워커와 오프라인 캐시.

## 저장과 음성

학습 기록은 `hajun-proverb-quest-v1` 이름으로 브라우저 localStorage에 저장합니다. 계정, 서버 저장, 기기 간 자동 동기화, 사용자 추적은 없습니다. 가져오기는 현재 기록을 교체하며 확인창이 있습니다. 초기화 역시 확인창이 있습니다.

음성은 Web Speech API를 사용합니다. 영어·일본어 음성이 설치된 실제 기기에서 재생됩니다. 언어 음성이 없는 경우 안내하며 다른 언어의 목소리를 억지로 선택하지 않습니다. 목소리를 반환하지 않는 브라우저에는 언어 태그로 시스템 기본 음성을 요청합니다. 음성 엔진에 따라 네트워크 연결이 필요할 수 있습니다. 마이크 녹음이나 발음 채점은 하지 않습니다.

카드를 ‘이해했어’로 넘기면 같은 날 카드당 10 XP. 퀴즈 정답은 15 XP. 정답 누적 1·2·3회 이후에는 각각 1·3·7일 뒤에 복습하도록 설정합니다. 틀린 카드는 즉시 복습 대상이며 다음 정답에서 오답 표시를 해제합니다. 배지는 정해진 학습 조건을 충족하면 받습니다.

## 콘텐츠 기준

한국어 뜻풀이·학습 상황·예문은 학습용으로 직접 작성했습니다. 영어와 일본어는 **유사한 생각을 비교**하는 것이며 정확한 번역 쌍이라고 주장하지 않습니다. 주요 표현은 Cambridge Dictionary와 コトバンク의 사전 항목을 참고했고 참고 링크는 앱 설정과 `SOURCES.md`에 있습니다. 히라가나는 원문의 읽기를 제공하며 한글 표기는 근사치입니다. 영어 `Even Homer nods`는 문어적인 표현이라는 안내가 있습니다.

## 배포

저장소의 기존 GitHub Pages 설정을 사용합니다. 상위 서비스나 파일을 변경하지 않고 `proverb-quest/`만 추가했습니다. 빌드가 필요 없으며 `index.html`부터 정적으로 제공하면 됩니다. PWA에는 HTTPS 또는 localhost가 필요합니다. 캐시 변경 시 `sw.js`의 캐시 버전도 변경합니다. 새 서비스 워커는 열린 기존 탭을 강제로 교체하지 않습니다.

## 검증

Node 구문 검사, 데이터 정합성, JSDOM으로 카드·언어 필터·즐겨찾기·네 가지 게임·오답 및 복습·기록 재로딩 경로를 확인합니다. 실제 브라우저 렌더링·휴대전화 설치와 실제 기기의 음성 재생은 별도의 기기 검증이 필요합니다.
