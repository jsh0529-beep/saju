# 윤시윤의 삿포로 여행

2026년 10월 9~11일, 성인 4명을 위한 모바일 여행 수첩. GitHub Pages의 `/saju/sapporo/`에서 실행하는 정적 웹앱입니다. 기존 경로를 변경하지 않습니다.

## 내용

- 제공된 예약 기준 항공편 네 구간 및 크로스호텔 삿포로 2박
- 첫날 도심, 둘째 날 조잔케이 가을 코스 / 오타루 / 실내 우천 대안, 셋째 날 공항 중심
- 공식 버스 시간표와 운임, 인천 환승전용 내항기 주의사항
- 지도 길찾기, 호텔 주소 복사, 전화, 일본어 큰 글씨와 지원 기기 음성
- 기기 내 체크리스트·메모·지출·환율 계산·JSON 백업
- 선택 코스 캘린더(ICS), 인쇄, 오프라인 기본 자료
- 페이지 접속 시 Open-Meteo 예보 조회, 오류·이전 예보 구분

## 공개 범위

예약번호, 탑승객 영문 이름, 좌석번호, 개인 연락처, 예약 원본 이미지와 인증정보는 포함하지 않습니다. 여행 제목·일정·숙소는 요청된 안내를 위해 공개됩니다. `noindex`는 검색 제외 요청이며 접근통제가 아닙니다.

개인 기록은 해당 브라우저의 localStorage에만 저장됩니다. 서버·일행 기기에 동기화하지 않습니다. 공유 기능은 공개 페이지 URL만 공유합니다. 외부 지도·번역·날씨 서비스의 개인정보 처리방침은 각 서비스에 따릅니다.

## 운영

별도 설치·빌드·API 키가 필요하지 않습니다. `index.html`, `style.css`, `data.js`, `app.js`를 정적으로 제공합니다. 서비스워커는 `/sapporo/` 하위에만 적용합니다. 새 버전을 배포하면 `sw.js`의 캐시 버전도 올리세요. 기본 파일 캐시 완료 후 오프라인 안내가 표시됩니다. 외부 지도·번역·최신 예보는 온라인 연결이 필요합니다.

날씨는 실시간 보장 서비스가 아닙니다. 일본어 TTS는 기기의 일본어 음성이 있을 때만 재생하고 없으면 외부 번역 대안을 제공합니다. 환율은 수동 입력값이며 초기 숫자는 예시입니다. 버스·식당·관광 티켓 예약과 결제는 수행하지 않았습니다.

## 자료 확인

확인 기준 2026-10-04. 공개 페이지의 ‘정보 출처·개인정보 안내’에서 공식 링크를 확인할 수 있습니다. 항공편·호텔은 사용자 제공 예약 화면 기준. 도보·관광·식사 시간은 계획용 추정이며 현장 공지를 우선합니다.
