# 하준이의 태양 연구소

초등학교 6학년 과학의 태양 고도·남중고도·그림자·계절 관계를 직접 조작하며 배우는 정적 웹앱입니다.

**앱:** https://jsh0529-beep.github.io/saju/sun-lab/

## 구성

- 태양 실험실: 대구·서울·부산·제주, 4개 절기 모형, 태양 시각 조절, 하루 재생, 막대 높이 조절, 관찰 저장, 4개 발견 미션
- 계절 탐험: 동일 지역·1m 막대·남중 시점의 4계절 비교, 햇빛 입사각에 따른 단위 면적 에너지 실험, 자전축 기울기 비교
- 각도 탐정: 그림과 그림자에서 각도를 어림하는 5문제 게임, 오차 5° 이내 별, 최고 기록
- 확인 퀴즈: 12문제, 즉시 설명, 한국어 풀이 듣기, 오답만 다시 풀기
- 연구 노트: 최근 20개 관찰, 수집 배지, 핵심 요약, 선택적 기록 초기화
- 반응형 화면, 키보드 조작, 동작 줄이기 설정 대응, 소리 켜기/끄기
- PWA 설치 안내·지원 브라우저 설치 요청, 자체 범위 서비스 워커, 첫 로딩 캐시 완료 후 오프라인 기본 학습
- SVG 파비콘, PNG 앱 아이콘, 공유 미리보기 이미지, 외부 폰트 요청 없는 한국어 폰트

## 과학 모형과 적용 범위

지역은 모두 대한민국(북위 33.50–37.57°)입니다. 남중 때 태양은 남쪽, 그림자는 북쪽입니다. 전 지구의 모든 위도에 대한 일반화가 아닙니다.

계절 버튼은 계절 평균이 아니라 춘분·하지·추분·동지 무렵을 대표합니다. 태양 적위를 0°, +23.4°, 0°, −23.4°로 고정합니다. 시각은 남중이 12:00인 **진태양시를 단순화한 학습용 태양 시각**이며 한국 표준시(KST)가 아닙니다. 실제 남중 시각은 날짜와 경도, 균시차의 영향을 받습니다.

- 태양 고도: asin(sin(latitude) × sin(declination) + cos(latitude) × cos(declination) × cos(hourAngle))
- 남중고도: 90° − |latitude − declination|
- 수직 막대 그림자: height / tan(altitude), 고도 ≤ 0°에서는 직사광 그림자 없음
- 기하학적 낮 길이: 2 × acos(−tan(latitude) × tan(declination)) / 15°
- 단위 면적 입사 에너지: sin(altitude), 90°를 100%로 정규화

대기 굴절, 태양 원반 크기, 지형, 건물, 구름은 계산에 포함하지 않습니다. 낮 길이는 태양 중심이 지평선 위에 있는 시간으로 실제 일출·일몰표와 다릅니다. 하늘 장면은 시간을 가로축으로 펼친 도식이며 천구의 원근 투영이 아닙니다. 각도와 그림자 패널은 서로 평행한 햇빛을 사용한 옆모습입니다. 매우 긴 그림자는 표시 영역에서 잘리고 수치로 길이를 제공합니다. 태양은 실제 관측에서 직접 바라보지 않도록 안내합니다.

참고 자료 (2026-10-08 확인):

- 한국천문연구원: https://astro.kasi.re.kr/life/pageView/10
- NOAA 계산식: https://gml.noaa.gov/grad/solcalc/solareqns.PDF
- NASA 어린이용 계절 설명: https://spaceplace.nasa.gov/seasons/en/

## 실행과 검증

빌드 단계가 없습니다. 이 폴더를 정적 서버에서 제공하면 됩니다. ES 모듈을 사용하므로 `file://`로 HTML만 여는 대신 HTTP(S) 서버로 실행합니다. GitHub Pages에서 `/saju/sun-lab/` 경로로 바로 동작합니다.

```
npm install
npm test
npm run test:ui
```

`science.test.js`는 별도 설치 없이 실행됩니다. `ui.test.cjs`는 jsdom이 필요합니다. UI 테스트는 과학 계산의 독립 기준값, 지역/계절/시간 조합, 전체 학습 흐름, 오답 복습, 기록 저장/복원, 라벨과 ID를 확인합니다. 테스트에서 만들어지는 도식 점검 산출물은 임시 경로에 저장하고 저장소에 넣지 않습니다.

검증 범위: 수학적 기준값과 낮 길이/그림자/남중 성질, 112개 지역·계절·시각 상태, 4개 발견 미션, 5문제 게임, 12문제 퀴즈와 오답 재시험, 새 창의 저장 복원, 6개 배지, 설정 대화상자, 초기화. 코드로 렌더링한 SVG 도식도 시각 점검했습니다. 이 개발 환경에는 승인된 브라우저 QA 기능이 없어 실제 브라우저 레이아웃·기기 음성·OS 설치·서비스 워커 오프라인 전환은 자동 실기 검증하지 못했습니다.

## 저장과 오디오

학습 기록은 `localStorage`의 `hajun-sun-lab-v1`에만 저장합니다. 계정, 서버, 위치 추적, API 키가 없고 다른 기기와 자동 동기화하지 않습니다. 브라우저 데이터 삭제 시 기록이 사라집니다. 저장 불가 환경은 화면에 안내합니다. 효과음은 Web Audio, 읽어 주기는 기기의 한국어 음성 합성을 사용합니다. 음성은 기기 설정에 따라 추가 다운로드나 인터넷 연결이 필요할 수 있습니다.

캐시는 `hajun-sun-lab-` 접두사만 관리합니다. 다른 앱의 캐시를 삭제하지 않습니다. 새 서비스 워커 버전은 기존 앱 탭이 모두 닫힌 후 활성화되며 파일 버전을 섞지 않습니다. 파일 수정 배포 시 `sw.js`의 버전도 올려 주세요.
